1. Déshabillage
Figure : c4bp06sc
Déposer :
  • L’ensemble bras-balai d’essuie-vitre (1)
  • Les éclaireurs de plaque de police (3)
  • Le gicleur de lave-vitre (2)
  • Le bandeau de volet arrière (4)
Figure : c4bp06tc
Ouvrir le volet arrière .
Déposer :
  • Les vis (5),(6),(9),(10)
  • Les vis (7) (de chaque côté)
  • L’agrafe (8) (de chaque côté)
  • La garniture (11) de volet arrière
Figure : c4bp06uc
Déconnecter :
  • La résistance de la lunette arrière (17)
  • Le moteur essuie-vitre (15),(16)
  • Les éclaireurs de plaque de police (13),(14)
Déposer vis (12).
Figure : c4bp06vd
Fixer les faisceaux électriques à une ficelle ( 22).
Tirer les faisceaux électriques hors du volet arrière.
Déposer :
  • La gâche (vis 23)
  • Le barillet (vis 24)
  • Le moteur essuie-vitre (vis 20)
  • Les passe-fils (18),(19),(21)
2. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.
