Figure : e5-p07kd
[ 1] appareil pour dépose-repose de support élastique, 9516-T.A.
[ 2] goupilles de maintien :
  • [2a] : Ø 10 , 9516-T.B1
  • [2b] : Ø 8 , 9516-T.B2
Figure : e5-p07lc
[ 3] jeu de pièces pour dépose-repose de support élastique :
  • [3a] : Cerclage de maintien, 9516-T.C1
  • [3b] : Demi-coupelle, 9516-T.C2
  • [3c] : Demi-coupelle, 9516-T.C3
Figure : e5-p07mc
[ 4] mandrin de positionnement, 9516-T.D.
2. Dépose
Figure : b3cp01xc
Positionner le bras de suspension ( 1) dans l’outil [1].
Figure : b3cp01yc
Engager l’outil [ 3a] sous le support élastique (2).
Positionner l’outil [ 3b] dans l’outil [3a].
NOTA : Plaquer l’outil [ 3b] sur le plot [1.1] de l’outil [1].
Figure : b3cp01zc
Positionner l’outil [ 3c] dans l’outil [3a].
Figure : b3cp020c
Plaquer le support élastique ( 2) sur l’outil [3].
Figure : b3cp021c
vis [1.2] : Graisser le filet.
Positionner l’extracteur [1.3] de l’outil [1].
Figure : b3cp022c
Avec les vis [1.4], Positionner le bras de suspension (1) dans l’alignement de la vis [1.2].
Figure : b3cp023c
À l’aide de vis [1.2], Extraire le support élastique.
3. Repose
3.1. Bras de suspension avant gauche
Figure : b3cp024d
Positionner le bras de suspension ( 1) dans l’outil [1].
Poser les goupilles [ 2] de maintien du bras de suspension sur l’outil [1].
Positionner la patte " a" du support élastique (2) dans le guide [1.5].
NOTA : Le guide détermine l’orientation du support élastique sur le bras de suspension.
3.2. Bras de suspension avant droit
Figure : b3cp025d
Positionner le bras de suspension ( 1) dans l’outil [1].
Poser les goupilles [ 2] de maintien du bras de suspension sur l’outil [1].
Positionner la patte " a" du support élastique (2) dans le guide [1.6].
NOTA : Le guide détermine l’orientation du support élastique sur le bras de suspension.
3.3. Repose (suite)
Figure : b3cp026c
Poser l’outil [ 4] sur le support élastique (2).
Engager la vis [ 1.2] dans l’outil [4].
Avec les vis [1.4], Positionner le bras de suspension (1) dans l’alignement de la vis [1.2].
Figure : b3cp027c
ATTENTION : Le support élastique ( 2) est monté serré sur le bras de suspension. Le montage du support élastique (2) doit s’effectuer avec un effort à l’emmanchement. Lorsque le support élastique (2) se monte librement, procéder au remplacement du bras de suspension.
À l’aide de la vis [ 1.2] et de l’outil [4], Engager le support élastique (2) dans le bras de suspension (1) jusqu’à mise en butée de l’outil [4].
Déposer le bras de suspension ( 1) de l’outil [1].
Figure : b3cp028c
Contrôler la cote entre les deux supports élastiques : X = 313 mm ± 0,5 mm.
