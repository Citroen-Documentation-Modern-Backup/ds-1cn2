B2BT01P0Évolution : Câble d’embrayage
Date d’application : 11/94.
Véhicules concernés : ZX tous types.
1. Ancien montage
Figure : b2bp02dc
2. Nouveau montage
Figure : b2bp02ec
3. Description
Le système d’accrochage du câble d’embrayage type "harpon" " A" est remplacé par un système type "à chape" "B".
Nouvelles pièces :
  • (1) Câble d’embrayage
  • (2) Pédale d’embrayage
  • (3) Agrafe sur pédale (ressort)
4. Réparation
Les anciennes pièces sont toujours fournies par les pièces de rechange.
Les nouvelles pièces ( 1) ; (2) se montent en lieu et place des anciennes.
IMPERATIF : Il est nécessaire de changer l’agrafe ( 3), à chaque pose du câble d’embrayage.
Course de la pédale d’embrayage : 150 mm .
